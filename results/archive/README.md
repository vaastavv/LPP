# Archived / suspect results

`*.suspect.jsonl` — files whose `model` field is labelled `llama-1b` but whose
numeric values byte-identically match a Qwen-0.5B run on the same prompts
(verified 2026-09-29: identical `min_entropy`, `max_ER`, `max_PR`,
`last_layer_ER`, `last_layer_PR`, `num_tokens` to 13 significant digits — not
reproducible with two different transformer weights).

Almost certainly generated by an earlier session where `HF_MODEL` was pointed
at a Qwen checkpoint (or config was patched) while `--model llama-1b` was
passed on the command line. The `accuracy_llama-1b.suspect.jsonl` also uses
`\boxed{}` throughout, which is Qwen2.5's math-formatting style, not
Llama-3.2's.

Kept for provenance. Do not include in analysis; regenerate a real Llama run
via `huggingface-cli login` first and then `python run_experiments.py --model
llama-1b` / `python run_latent.py --model llama-1b`.
